# 选题说明

**题目：基于遗传算法的高校排课系统的设计与实现**

面向本人所在大学的普通本科行政班，先以信息工程系为试点，建设可部署到自有云服务器的 Web 系统。

核心流程：教学任务导入 → 种群初始化 → 遗传迭代与冲突修复 → 冲突复查 → 人工调整与发布。

首版围绕教师、班级、教室冲突和教学课时要求，提供数据导入、自动排课、调整、课表查询与导出。算法采用统一编码和校验器，通过与贪心基线的对比实验评价可行率、软约束代价及耗时。

已有学校院系、专业、教室和课程评估资料；教学任务、周学时、任课教师、教室容量等仍需补充。当前系统处于文档和工程骨架阶段。

详见[开题报告正文](proposal.md)。
