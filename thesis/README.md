# thesis

毕业论文。论文正文与工程文档（`docs/`）分开维护，本目录只放论文相关材料。

| 目录 | 用途 |
|---|---|
| `templates/` | 学校论文模板 |
| `chapters/` | 各章正文，按章节编号命名 |
| `figures/` | 插图源文件：架构图、流程图、ER 图、截图 |
| `tables/` | 表格源文件 |
| `references/` | 文献列表（xlsx）与 PDF 原文（不入库） |
| `draft/` | 过程稿 |
| `final/` | 定稿与签字版 |

## 章节安排

1. 绪论
2. 相关理论与技术
3. 需求分析
4. 系统设计
5. 系统实现
6. 实验与测试
7. 总结与展望

## 约定

- 图、表在 `figures/`、`tables/` 保留可编辑源文件（drawio、xlsx），导出图另存。
- 参考文献列表与正文标号一致，格式按 GB/T 7714。
- `final/` 只放定稿，过程稿留在 `draft/`。
