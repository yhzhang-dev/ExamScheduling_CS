# process_materials

学校要求的过程材料，按时间节点归档。文件名保持学校原始命名，不改写。

| 目录 | 对应节点 |
|---|---|
| `01_task_book/` | 任务书（教师下达） |
| `02_proposal/` | 开题报告与开题答辩材料 |
| `03_midterm/` | 中期检查表与中期报告 |
| `04_guidance/` | 指导记录 |
| `05_plagiarism/` | 查重报告 |
| `06_other/` | 过程材料清单与其他表格 |

## 约定

- 每个节点完成后立即归档，避免答辩前集中补。
- 签字版、盖章版单独保留，不覆盖电子稿。
- 需要提交的表格以学校模板为准，不自行改版式。
