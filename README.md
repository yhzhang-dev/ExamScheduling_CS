# CourseScheduling_CS

高校混合算法排课系统：贪心构造初始方案，遗传算法优化，模拟退火改进。

毕业设计题目：**基于贪心、遗传与模拟退火混合算法的高校排课系统的设计与实现**。

首版采用 Web 系统，以本校普通本科行政班为试点，完成教学任务导入、自动排课、冲突检测、手动调整和课表查询。后端 Java + Spring Boot，前端 Vue 3，数据库 MySQL，部署到自有云服务器。当前仓库以文档和工程骨架为主，算法与业务功能尚待实现。
