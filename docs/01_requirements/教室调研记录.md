- `C405` 的楼栋与正式编号，以及 `茶艺C2` 的位置、用途和考试可用性。
- `综合教学楼B508` 与 `综合教学楼B508B` 是否为两间独立教室。
- 文科楼重复项及带前导零的编号是否对应同一房间；雕塑实训室是否允许安排常规考试。
- 实验中心各房间、大气实验室、`实验室210` 与 `实验楼408A` 的正式位置、设备限制和考试适用类型。
- 体育馆房间与篮球馆的实际用途；若仅用于体育课程或活动，不计入普通笔试考场容量。
- 专用实训基地、室外场地与校外基地是否参与任何类型的考试；若参与，应单独标注适用考试类型和容量。
