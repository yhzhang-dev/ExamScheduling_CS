# 本科年级与学期范围

> 决定：项目负责人于 2026-11-10 确定首版只考虑普通本科，不纳入专科。

## 适用范围

- 学生年级只使用“大一”“大二”“大三”“大四”四档。
- 不建立专科年级、专科教学班或专科排考流程。
- 已收集的 [本科专业名单](本科专业调研记录.md)作为专业调研起点；实际开设专业、年级和班级人数仍以学校当学期数据为准。

## 年级与学期的区别

“大一”至“大四”是学生所在年级，不是一次排考的学期。排考批次仍需用“学年 + 上/下学期”标识，例如“2026—2027 学年第一学期”；考试周日期与每天可排时段另行配置。按四年、每学年两学期的通常结构，共有第一至第八学期，但不以该序号代替实际学年学期。

学生重修、跨年级选课或参加公共课时，冲突检测以该场考试的实际考生名单为准，不只按年级或行政班推断。

## 后续需核实

- 学校学年、上/下学期和考试周的正式命名与日期。
- 各年级实际开课和考试计划，以及跨年级选课、重修的处理方式。
