## 编写约定

- 需求用「角色—场景—约束」组织，不写成功能清单。
- 约束清单是全文的核心：硬约束逐条编号（C1…），软约束（S1…）注明权重含义，后文设计与实验都引用同一套编号。
- 接口文档与 `03_api/openapi.json` 保持一致，改接口时同步改两处。
- 表结构与 `database/schema.sql` 保持一致。
