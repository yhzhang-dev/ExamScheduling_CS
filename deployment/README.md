# deployment

部署与运行环境。目标形态为本地或实验室服务器单机部署，不依赖云服务。

| 目录 / 文件 | 用途 |
|---|---|
| `docker/` | 后端与前端的镜像定义、`docker-compose.yml` |
| `nginx/` | 反向代理与静态资源配置 |
| `scripts/` | 启动、初始化数据库等脚本 |
| `env.example` | 环境变量样例，**不含真实口令** |

## 约定

- 仓库只提交 `env.example`；真实 `.env` 由使用者在本地创建。
- 数据库连接、端口、密钥一律从环境变量读取，不写死在代码里。
- 部署说明同步维护在 `docs/05_deployment/`。
