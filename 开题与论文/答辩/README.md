# 答辩

答辩材料。

| 目录 / 文件 | 用途 |
|---|---|
| `slides.pptx` / `slides.pdf` | 答辩 PPT |
| `speech.md` | 答辩讲稿 |
| `Q&A.md` | 预期问题与回答准备 |
| `demo/demo_video.mp4` | 系统演示录屏（本地网络不通时的备用） |
| `demo/screenshots/` | 关键界面截图 |

## 准备要点

- 讲稿按「问题 → 建模 → 算法 → 系统 → 实验」组织，控制在规定时长内。
- 演示环节准备**离线可跑**的方案：本地部署，不依赖外网。
- 预期问题至少覆盖：为何不用商业软件、算法为何不选遗传算法、数据来源与真实性、约束遗漏的风险。
