# 开题与论文

写开题报告时先看前三项；其余目录按学校后续节点使用。

| 目录 | 用途 |
|---|---|
| [开题报告](开题报告/README.md) | 开题正文 `proposal.md`、单页选题说明及导出文件 |
| [调研资料](调研资料/README.md) | 学校院系、专业、班级、教室、课程等原始资料与梳理 |
| [系统设计](系统设计/功能结构设计.md) | 功能结构、约束与总体技术方案 |
| [论文](论文/README.md) | 论文正文、图表和参考文献 |
| [过程材料](过程材料/README.md) | 任务书、中期、指导记录和查重材料 |
| [答辩](答辩/README.md) | 幻灯片、讲稿和演示材料 |
| [最终提交](最终提交/README.md) | 学校要求的定稿文件 |

学校调研和系统设计会同时服务于 [项目代码](../项目代码/README.md)，但文件只保留一份，避免两个版本不一致。
