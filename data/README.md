# data

测试与实验数据。**样本数据与源码分离**，数据集可独立替换。

| 目录 | 用途 |
|---|---|
| `raw/` | 原始数据：考试、课程、学生选课、考场、教师、约束配置（CSV） |
| `processed/` | 清洗并按规模切分后的实例：`small_case` / `medium_case` / `large_case` |
| `samples/` | 面向教务的导入模板（Excel），字段与 `raw/` 对齐 |

## 字段说明（待补充）

导入前需明确：考试与教学班的对应关系、学生选课数据的最小必要字段、教室容量口径（座位数还是可用座位）、教师可用时段的表示方式。

## 约定

- 原始数据只读，清洗结果写入 `processed/`，不改原文件。
- 每份数据集标注来源与生成方式：真实数据 / 模拟生成（附生成参数与种子）。
- 涉及真实师生信息的数据不入库，脱敏后再提交。
