# experiments

算法实验与结果分析，对应论文第 6 章。

| 目录 | 用途 |
|---|---|
| `configs/` | 实验参数：规模、约束密度、算法参数、随机种子 |
| `scripts/` | 批量运行、性能对比、结果统计脚本 |
| `results/raw/` | 原始输出（JSON/CSV），可重建，不入库 |
| `results/tables/` | 汇总表，直接进论文 |
| `results/figures/` | 图表源文件与导出图 |
| `logs/` | 运行日志，不入库 |

## 可复现要求

- 每个实验固定随机种子并在配置文件中写明。
- 结果文件带时间戳与配置哈希，避免「这张表是哪次跑出来的」说不清。
- 对照策略固定为四组：纯贪心、DSatur、DSatur + 装箱、全流程（再加监考匹配与局部搜索）。
- 指标口径统一：硬冲突数、软约束加权代价、求解耗时、监考工作量标准差、教室利用率。
