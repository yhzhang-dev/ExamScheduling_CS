# 本科专业与院系对应

> 来源：项目负责人于 2026-11-10 提供的各系现有专业名单。用于首版普通本科排课范围；专业是否在每个年级实际招生和开课，仍以当学期教务数据为准。

| 院系 | 本科专业 | 数量 |
|---|---|---:|
| 信息工程系 | 物联网工程、软件工程、数据科学与大数据技术、智能科学与技术 | 4 |
| 环境科学系 | 环境科学、环境科学与工程、海洋资源与环境 | 3 |
| 环境工程系 | 环境工程、环保设备工程、水质科学与技术 | 3 |
| 生态学系 | 环境生态工程、园林、食品质量与安全 | 3 |
| 环境艺术系 | 环境设计、产品设计、视觉传达设计 | 3 |
| 经济与管理系 | 物流管理、市场营销、国际商务、工程造价、工程管理 | 5 |
| 人文社科系 | 会展经济与管理、新闻学、旅游管理与服务教育、网络与新媒体 | 4 |
| 体育系 | 社会体育指导与管理、休闲体育 | 2 |
| **合计** | **8 个系、27 个本科专业** | **27** |

环境工程专业含“中芬合作环境工程办学项目”，这里按同一本科专业记录，办学项目是否需要单独的教学班或教学安排待核实。环境工程系另有“环境工程技术”专科专业，因首版 [仅面向普通本科](本科年级与学期范围.md)，不纳入排课范围。

先前的 [阳光高考专业介绍名单](本科专业调研记录.md)共有 29 个名称，其中“数字媒体艺术”和“碳中和科学与工程”未出现在这次提供的现有院系专业清单中；先保留为历史资料，待核实是否仍有在校生或开课。马克思主义学院未在本次本科专业归属清单中列出专业；其公共课与开课单位关系另行调查。
