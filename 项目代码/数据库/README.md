# 数据库

建表、种子数据与迁移脚本。本目录的 SQL 是表结构的唯一权威来源，[工程文档的数据库说明](../工程文档/04_database/)必须与之一致。

| 文件 / 目录 | 用途 |
|---|---|
| `schema.sql` | 全量建表脚本，按依赖顺序排列 |
| `seed_data.sql` | 基础字典与演示数据（学期、时段、教室、角色等） |
| `migrations/` | 结构变更脚本，按 `001_xxx.sql` 编号，只追加不修改 |
| `backup/` | 本地备份，不入库（见 `.gitignore`） |

## 约定

- 字符集 `utf8mb4`，精确时刻统一存 UTC，`DATE` 字段存本地日期。
- 业务数据以状态位软删除，不做物理删除。
- 每个迁移脚本写明「为什么改」，并在开发日志留一行记录。
