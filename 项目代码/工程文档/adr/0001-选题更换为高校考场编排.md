# ADR-0001 选题更换为「高校考场编排与监考分配」

- **状态**：提议中（待指导教师确认）
- **日期**：2026-11-02
- **依据**：现归档于[功能结构设计](../../系统设计/功能结构设计.md)及[项目说明](../../../README.md)的选题材料
- **决策者**：学生本人，指导教师已口头提出更换意见

## 背景

指导教师认为「健身 / 健康管理」类题材的重复度高，建议更换题目。

在此之前，本项目已经经历过多次选题调整，累计七版：个人生活数据管理、三角色管理平台、健身、社交化健身等。这些题目全部作废，只保留了框架层代码（登录鉴权、前后端骨架、数据库与部署骨架）。

## 决策

把选题更换为**高校考场编排与监考分配**。

它的技术核心是**多约束组合优化**（把考试排进「时段 × 教室」，再把监考教师匹配到每一场，同时满足学生不冲突、教室容量、教师回避、监考均衡等约束），而不是增删改查。系统按「着色 → 装箱 → 匹配 → 局部搜索」分阶段求解，并用冲突数、软成本、工作量标准差、教室利用率等指标评价方案质量。

## 后果

- **可复用**：`server` 的工程骨架、鉴权与权限、数据库访问层、REST 约定；`admin` 与 `android` 的框架、路由、请求封装；`database` 的库表规范与迁移文件组织方式。
- **需废弃或重写**：`server` 的 `ledger`（记账）、`journal`（日志与训练）、`wellness`（身体与睡眠）三个业务域；`admin` 与 `android` 中对应的页面。
- **论文需重写**：`thesis/03-初稿-第3章-系统设计.md`、`04-初稿-第4章-系统实现.md`、`05-初稿-第5章-测试与结果.md` 三章初稿均基于旧题材，新题材下不能直接沿用。
- **文献需重找**：`papers/` 与 `thesis/11-文献/` 现有两篇（自我量化 / 体育中的个人信息化）服务于旧题材。
