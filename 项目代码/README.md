# 项目代码

这里放运行系统需要的工程文件。当前多数业务目录还是骨架，代码实现将在需求和约束确定后逐步补齐。

| 目录 | 用途 |
|---|---|
| [源码/backend](源码/backend/README.md) | Java 服务端与排考求解器 |
| [源码/frontend](源码/frontend/README.md) | 教务端和教师端 Web 页面 |
| `源码/shared/` | 前后端共享的常量与类型预留位置 |
| [数据库](数据库/README.md) | 建表、迁移和种子数据 |
| [部署](部署/README.md) | 容器、反向代理和启动脚本预留位置 |
| [工程文档](工程文档/README.md) | 接口、数据库、部署、手册与架构决策说明 |

开题相关的学校调研和系统功能设计在[开题与论文](../开题与论文/README.md)。
